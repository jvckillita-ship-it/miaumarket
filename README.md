# MIAUMARKET

Catálogo web de MIAUMARKET: ropa, calzado y accesorios de marca. Cada producto se pide por WhatsApp.

- `docs/`: la página publicada (GitHub Pages, carpeta /docs).
- `fuente/`: diseño (`template.html`), datos de productos (`data.json`) y `build.py`, que regenera `docs/index.html`.
- `docs/whatsapp.html`: hoja de carga del catálogo de WhatsApp Business (`fuente/build_whatsapp.py`).
